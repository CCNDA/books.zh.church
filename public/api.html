開放 API

屬靈共同書目的書目資料以 JSON 開放取用,不用申請、不用金鑰,教會、機構與開發者都可以直接使用。只提供讀取(GET);回應都包在 data 裡,錯誤時是 {"error": "說明"} 與對應的 HTTP 狀態碼(例如找不到書是 404)。

請合理使用:需要大量資料時,請放慢速度、把結果暫存起來,不要短時間內反覆抓取。引用書目時請註明出處「屬靈共同書目(books.zh.church)」,並以各出版社公布的資訊為準。

搜尋與瀏覽書目

GET /api/books:所有條件都可以一起用;沒有任何條件時依上架時間由新到舊列出。

/api/books 的查詢參數
參數說明例子
q關鍵字:書名、作者、出版社、ISBNq=羅馬書
deep1＝關鍵字也搜內容簡介(比較慢)deep=1
category分類編號(見 /api/categories)category=9
person作者/譯者等貢獻者編號(見 /api/persons)person=18991
publisher出版社編號(見 /api/publishers);同一家出版社的不同寫法會一起算publisher=2748
year_from、year_to出版年範圍(西元四位數)year_from=2020&year_to=2025
source來源書房代碼(見 /api/sources 的 code)source=logos
page、per_page第幾頁、每頁幾本(1–50,預設 20)page=2&per_page=50

回應的 data 有 items(書目清單)、total(符合的總數)、page、per_page、pages。每本書有 book_id、title、author、publisher、publish_date、isbn13、cover_url、summary_short、category_name 等欄位。

curl "https://books.zh.church/api/books?q=羅馬書&per_page=5"

單本書目

GET /api/books/{book_id}:一本書的完整資料,包含內容簡介、作者與譯者(contributors)、各書房的版本與購書連結(editions、buy_links)、叢書與主題。網頁版是 https://books.zh.church/book/{book_id}。

curl "https://books.zh.church/api/books/38080"

最新上架、熱門書目

GET /api/books/latest、GET /api/books/popular:limit 1–20,預設 6。

分類、作者、出版社、來源書房

查編號用的端點
端點說明
GET /api/categories全部分類:category_id、name、book_count
GET /api/persons?q=找作者/貢獻者:person_id、name、book_count;不帶 q 時依著作數列出。limit 1–50,預設 15
GET /api/publishers?q=找出版社:publisher_id、name_zh、book_count;用法同上
GET /api/sources收錄的網路書房與出版社:code、name、region、url、book_count,以及全站上架總數 total
GET /api/version目前網站版本

例子:找某位作者的書

curl "https://books.zh.church/api/persons?q=賴特"          # 先查作者編號
curl "https://books.zh.church/api/books?person=編號"         # 再用編號查他的書

其他

給 AI 與搜尋引擎的網站說明在 llms.txt,所有書目頁的清單在 sitemap.xml。發現資料有誤或有使用上的問題,歡迎與中華基督教網路發展協會(CCNDA)聯繫。

# Claude Project 設定:屬靈書目-內容

附屬專案(內容編輯),與「屬靈書目-開發」分工:本專案只做書目資料整理與維運,不處理程式開發。

## 建立步驟

1. Claude 左側選單 → Projects → Create project,名稱:**屬靈書目-內容**
2. 把 `project-instructions.md` 整段貼入 Set project instructions
3. 將 `knowledge/` 內六個檔案上傳至 Project knowledge

## 知識庫檔案說明(已備妥於 knowledge/)

- `CategoryV11.xls`:官方分類系統(757 項,區類+編號+中英類別)
- `書籍資料.docx`:圖書完整資訊欄位規格
- `整合_完整書籍資料庫模板.xlsx`:00_快速匯入表格式
- `A20210304校園圖書目錄.xls`、`出版物資料庫.xlsx`:既有書目來源
- `20250926_基督徒圖書分享服務企劃書.docx`:維運與資料整理原則

若使用 Cowork,亦可直接把本資料夾(contents/)設為該 Project 的工作資料夾。

# 教會公報社樣本頁存放區

Claude 的抓取工具對 buy.pctpress.org 一律拒絕(該站 robots.txt 為全站 Disallow),
且不允許改用其他方式取頁。因此偵察階段改為:**熊哥存頁、Claude 讀檔分析**。

請把下列頁面存進本資料夾(Chrome:Ctrl+S → 存檔類型選「網頁,僅 HTML」;
或 Ctrl+U 看原始碼後複製貼成 .html 檔亦可):

| 檔名 | 頁面 |
|---|---|
| 01-new-books-p1.html | https://buy.pctpress.org/cat/new_arrival/new_books/ |
| 02-new-books-p2.html | 同上清單的第 2 頁(若有分頁) |
| 03-new-books-overflow.html | 同上清單的超界頁(例如 ?page=999) |
| 04-product-sample.html | 任一商品詳情頁 |
| 05-category-menu.html | 首頁或任一分類頁(要看得到完整分類選單) |

存好後跟 Claude 說一聲即可,不必貼內容。

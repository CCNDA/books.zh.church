# 開發進度摘要

更新日期: 2026-03-28

## 已完成項目

- 前台: 書籍清單、搜尋、書籍獨立網址頁。
- 後台: admin.php 管理清單，admin_book.php 雙模式建檔。
- 認證: Magic Link 無密碼登入（含 token 驗證流程）。
- 郵件: AWS SES SMTP（587 + STARTTLS）。
- 資料庫: books、users、magic_links 與書目正規化相關表。
- 匯入: 支援博客來、校園書房、基道網址抓取預填。
- 媒體: 匯入封面圖支援落地儲存與 fallback。

## 近期修正重點

- 修復 UTF-8 BOM 導致 strict_types 錯誤。
- 修復部署環境因設定檔缺失導致 DB 連線失敗。
- 修復 magic_links 資料表缺漏造成登入失敗。
- 修正博客來書名與副標拆分規則（例: 主標：副標）。
- 強化 403 情境抓取策略與備援路徑。

## 目前開發重點

- 持續提高外站欄位映射精度。
- 補強匯入失敗時的人工貼文備援流程。
- 完整化進階編輯模式對關聯資料的更新能力。

## 已知風險

- 部分外站仍可能因 WAF/CDN 封鎖而回應 403。
- 不同來源站欄位格式差異大，需持續調整解析規則。

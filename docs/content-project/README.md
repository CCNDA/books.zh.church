# Claude Project 設定:屬靈書目-內容

附屬專案(內容編輯),與「屬靈書目-開發」分工:本專案只做書目資料整理與維運,不處理程式開發。

## 建立步驟

1. Claude 左側選單 → Projects → Create project,名稱:**屬靈書目-內容**
2. 把 `project-instructions.md` 整段貼入 Set project instructions
3. 把下列六個檔案上傳至 Project knowledge

## 1. 資料放哪裡（現況實查）

- 價格與有沒有貨：`formats_prices(edition_id, media_type, price, currency, availability)`。
  - `availability` 欄（varchar(50)，註解「庫存/上架狀態」）**全庫 83,728 筆都是 NULL**，從沒寫過。
  - API `app/lib/book_detail.php` 會把 availability 帶出去，但**前台目前沒顯示**。
- 購買連結：`links(edition_id, link_type='buy', platform, url, note)`，**沒有狀態欄**。

## 2. 寫回規則

1. **只動天道北美的 edition**：`editions.source='ustiendao'`。對應順序（小布 11/26 審查 b，依實查調整）：
   - 小布建議的 `identifiers(id_type='STORE')`：**正式庫實查 ustiendao 9,999 個 edition、有 STORE 的 0 個**（天道北美匯入沒寫），這個來源用不上
   - ⇒ 先用 `editions.source_url` 對報告的 url：**兩邊都用正規式取出商品號再比**（網址最後一段 `.html` 前面那串，例 `/1-22357000.html` → `1-22357000`；也有 `copy-of-21`、`20063` 這種，不能只取數字），不整串比（http／https、www、尾端參數不同會對不到；小布 11/26）
   - 同一個商品號對到兩個以上 edition（重複匯入）→ 不寫，列進人審清單（小布 11/26）
   - 再用 ISBN13 交叉核對：不符就歸「換本」（第 5 條），不寫
   - 對不到的列進「對不到」清單，不猜；之後可另開票替天道北美補寫 STORE 識別碼
2. **改價**：`formats_prices.price` 更新為新值；`currency` 必須是 USD 才寫（不是就停、列出來）
3. **有沒有貨**：值照 schema.org 原字（`InStock`／`OutOfStock`／`PreOrder`…）寫進 `availability`
   - 新值是 None（書頁沒標）→ **不動**（小布 11/24：不明不是缺貨）——這條只管「書頁給的值」
4. **下架 13 本**：`formats_prices.availability='Discontinued'`（schema.org 正式值）；`links` 不刪，`note` 加**固定標記**「[天道北美已下架]」（不帶日期）
   - 已含標記就不再加（冪等，小布 11/26 審查二）
   - **重新找得到**：Discontinued 是我們寫的、不是書頁給的 → 一律清掉；新值是 None 就寫回 NULL，有值就寫新值；`note` 的標記拿掉（小布 11/26 審查一：不然會卡在已下架）
5. **換成別本 4 本**：不寫；產一份 TSV（book_id、舊 ISBN、新 ISBN、書名、網址）給人審（可能是新版／再版）
6. **冪等**：同一份報告重跑結果一樣；只改「值真的不同」的列；單元測試「同一份報告跑兩次，第二次 0 筆」
7. **異常閘**（小布 11/26 審查三）：dry-run 算出的下架 > 50 本、或改價 > 50 本、或任一類超過天道北美總數 1%（約 100）→ **停、不產 SQL**，要人看過報告（爬蟲壞掉或對方網站出狀況會一次報出大量 404／改價）。這次 13／32 遠低於門檻

## 3. 工具

`tools/ustiendao_writeback.php <report.json> [--dry-run]`
- 讀報告 → 對 edition → 算出要改的列 → **產生一支 SQL 檔**（不直接寫庫）
- 正式庫寫入走 `ccnda-db-run`：先試跑（ROLLBACK）看筆數，數字對才 `--commit`（自動備份）
- 輸出：改價 N、availability 寫入 N、下架 N、對不到 N、換本 TSV 路徑

## 4. 前台顯示（要熊叔叔決定，見第 6 節）

書目頁購買連結旁顯示：
- `OutOfStock`：「缺貨」（灰色，連結照留）
- `Discontinued`：「天道北美已下架」，**不顯示購買鈕**（或灰掉）
- `InStock`、NULL：照現在（不加字）

## 5. 測試

- 單元：規則表（改價／None 不蓋／InStock 寫入／下架／換本不寫／幣別不是 USD 停）

- 正式：db-run 試跑筆數＝報告筆數才 commit

# 屬靈共同書目 — 服務開發企劃書(三個月執行版)

版本:2026-07-11|用途:對內執行依據|執行期間:2026-07-12 至 2026-10-12
主辦:CCNDA 中華基督教網路發展協會|網站:https://books.zh.church

---

## 一、緣起與願景

基督教書籍屬小眾出版,讀者因信仰階段不同而對圖書有殊異需求:歷久彌新的靈修經典、散落於教會群體的見證集、隨時代絕版的議題書籍。基督教出版社的新書資訊往往不走一般通路,在博客來、讀冊等平台上殘缺不全;讀者「找書難」、出版社「觸及難」,兩者之間缺少一個以信仰閱讀為核心的交流平台。

本計畫以「閱讀自主、共同學習」為基礎(希伯來書 5:12-14),打造**專屬基督教華文書籍的社群網站**:

- **近程**:建立華文屬靈書籍開放資料庫,解決「找書」問題
- **中程**:發展書評與書庫社群,促進讀者、出版社、推書者(KOL)的交流
- **長程**:提升為「華文基督徒共同知識庫」,以標籤化治理(出版社宗派背景、爭議性提示)取代中央裁決,支援 AI 時代的信仰學習(2026-01-30 會議定調)

## 二、參考服務分析

### Goodreads(goodreads.com)

全球最大書籍社群。核心模型:**書庫(shelves)+ 評分評論 + 社交追蹤**。可借鑑:想讀/在讀/已讀三態書櫃、五星評分與長短書評、年度閱讀挑戰、作者頁與系列頁、書單(Listopia)、以書會友的追蹤機制。

### 喵喵書評(meowbooks.tw)

台港最大繁中書評網站,「找好書就是快」。可借鑑:

- **書評家生態**:書評家等級制度(Lv.)、熱門書評家頁、個人專欄、說書(音頻/影片)
- **發現機制**:熱門/推薦雙排行榜、依分類瀏覽、最新書評流
- **出版社頁**:各社書目集中呈現(「時報出版好書推薦 1043 本」),對出版社有集客價值
- **評分呈現**:平均分直接掛在書名前(4.8 我可能錯了),資訊密度高
- 行動端:iOS/Android App(本案後續階段再議)

### 本案差異化定位

1. **信仰導向的資料深度**:CategoryV11 分類(757 項,神學/讀經/靈修等專業架構)、宗派背景標籤、聖經篇章關聯(後續)——一般書評站做不到
2. **絕版書與流通**:標註絕版、記錄可取得管道,承接基督徒之間圖書交流的獨特需求
3. **出版社共建**:與文協及台港出版社(校園、天恩、道聲、證主、漢語聖經協會等)合作供稿,而非單向爬取
4. **既有社群基礎**:台灣聖經網 4.5 萬會員、聖經網讀書會(2014 起)、靈糧點數獎勵制度可銜接

## 三、服務定位與目標用戶

| 用戶 | 需求 | 本服務提供 |
|---|---|---|
| 一般基督徒讀者 | 找適合自己信仰階段的書 | 多元搜尋、分類瀏覽、書評參考、購書連結 |
| 讀書會/教會小組 | 選書、共讀材料 | 書單、分類推薦、讀書會連結(後續) |
| 推書者(KOL/部落客) | 內容曝光平台 | 書籍推薦連結(YouTube/Blog/Podcast) |
| 出版社 | 新書觸及讀者 | 出版社頁、書訊訂閱、資料匯入通道 |
| 研究者/開發者 | 書目資料取用 | 開放 API |

## 四、功能規劃(三層架構)

### A. 資料層(基礎,7 月)

- 正規化書目資料庫(已完成):Work/Edition 模型 15 表,支援一書多作者/譯者/插畫(角色+排序+署名原文)、多版本、多 ISBN、多格式價格、多套分類系統並存
- **兩大線上書房全量資料**:校園書房(估 2.5-4 萬種)、基道 BookFinder(估數萬種),含書名/作者/出版社/ISBN/價格/庫存/簡介/封面,標注來源與連結
- 封面儲存:Cloudflare R2(imgr2.oursweb.net)
- 資料維運:ISBN 去重合併、CategoryV11 編碼、絕版標註(內容小組,依「屬靈書目-內容」專案)

### B. 檢索與呈現層(第一階段展示核心,7-8 月)

- **多種方式搜尋**:
  - 關鍵字全欄位(書名/副標/作者/譯者/出版社/摘要/ISBN)
  - 分類瀏覽(CategoryV11 樹狀 + 來源站分類)
  - 進階條件:作者、出版社、出版年份、語言、有無庫存
  - 依書房來源篩選(校園/基道/兩者皆有)
- 書籍詳情頁:完整書目、兩站價格與購書連結並列、封面、每書獨立短網址(/book/{id})、社群分享 meta
- 出版社頁、作者頁(該社/該作者全部書目)
- 排行與發現:新書上架、分類熱門(初期依瀏覽數)
- RWD 行動適配、組織簡介頁
- 開放 API(/api/books、/api/categories,讀取公開)

### C. 社群層(9 月起)

- 會員系統:Magic Link 無密碼登入(架構已備)
- 我的書庫:想讀/在讀/已讀三態(Goodreads 模型)
- 評分與短評論:五星評分 + 70 字以上短評、按讚實用度(喵喵模型)
- Email 訂閱:出版社/作者/關鍵字新書書訊
- 網友補充建檔(需審核)
- 暫不做(三個月後):書評家等級、專欄說書、二手流通、讀書會連結、靈糧點數、聖經網會員整合、App

## 五、技術架構(現況即基礎)

- PHP 8 + MariaDB(utf8mb4)REST API 前後端分離;Apache 虛擬主機(172.237.12.60),手動 FTP 部署
- 資料庫:books + 14 關聯表 + v_book_list 檢視表(migrations 001-004 已上線)
- 版控:GitHub CCNDA/books.zh.church;規範見 repo CLAUDE.md 與 books-zh-church-dev 技能
- 爬取:Python(節流 1req/2-5s、續跑、UA 表明身分),兩站偵察已完成(docs/crawler-recon.md)
- 郵件:AWS SES(訂閱功能用);封面:R2

## 七、維運規劃(上線後,依 2025 企劃書)

1. 資料:出版社/文協新書資料表整理、會員建檔覆核、絕版標註、商城連結維護
2. 社群:優良書評推薦轉貼(聖經網讀書會)、檢舉審核、讀書會資訊整理(後續)
3. 技術:增量爬取排程、備份、安全更新、API 用量監控

## 八、風險與對策

| 風險 | 影響 | 對策 |
|---|---|---|
| 爬取進度落後(4 萬頁×節流) | M0 展示資料不全 | 兩站並行;M0 可接受部分資料(如先完成主要分類),持續補抓 |
| 來源站封鎖/改版 | 資料中斷 | 節流禮貌抓取、UA 表明身分;續跑機制;必要時人工補 |
| 簡介/封面著作權 | 法律與關係風險 | 標注來源與連結;依合作管道向出版社取得授權;無授權者以自撰簡介替代 |
| 同名作者/無 ISBN 合併錯誤 | 資料品質 | 存疑不合併,留待人工;內容小組抽查 |
| 開發人力單薄(志工+AI 協作) | 時程延誤 | AI 開發助手 + 每日排程監控;功能界線嚴格(不提前做後續階段) |
| 社群冷啟動 | 上線後無內容 | 聖經網讀書會既有書評轉入、種子書評家邀請(參喵喵專欄模式) |

## 九、成功指標(10/12 上線時)

- 書目量:≥ 30,000 種(兩站合併去重後)
- 搜尋:關鍵字/分類/作者/出版社/年份/來源六種方式皆可用,行動端可用
- 資料品質:抽樣 100 筆錯誤率 < 5%;封面覆蓋率 ≥ 80%
- 社群:會員註冊與書庫/評分/短評功能上線,種子書評 ≥ 50 則
- API:公開文件 + 至少 1 個外部使用案例(如 LINE Bot 原型)

## 十、後續展望(三個月後)

書評家等級與專欄(喵喵模式)、讀書會連結、二手書流通(借閱/贈送/交換)、靈糧點數獎勵、台灣聖經網會員整合、聖經篇章關聯檢索、多語系、App、共同知識庫與 AI 應用(標籤化治理)。

# 致台灣教會公報社:「屬靈共同書目」收錄與資料合作請求(草稿)

> 草稿說明:**尚未寄出**(熊哥 8/24 指示先存檔)。寄出前請確認 ① 收件人與稱謂 ② 聯絡電話 ③ 目前收錄書目總數與書房家數(以 ⟨⟩ 標示)。

**主旨:**「屬靈共同書目」收錄貴社出版品之資料合作請求(CCNDA)

---

台灣教會公報社 敬啟：

平安。我們是 **社團法人中華基督教網路發展協會**(CCNDA),目前正在建置一項非營利的服務——**屬靈共同書目**(https://books.zh.church),目的是把散落在各家基督教書房與出版社的中文屬靈書籍,整理成一個統一、可搜尋的公開書目,讓弟兄姊妹、傳道人與神學生能在一個地方找到想讀的書,並直接連到各書房購買。

這項服務不販售書籍、不收取任何費用、也不放廣告。書目頁上的每一本書都會標明出版社,並提供「前往購買」的連結導回原書房的商品頁——**我們是把讀者送到貴社的網站,而不是把流量留在自己站上**。

目前已收錄 ⟨11⟩ 家書房與出版社、約 ⟨數萬⟩ 筆書目,包括校園書房、基道 BookFinder、以琳書房、天恩出版社、微讀書城、衛理書房、格子外面、道聲、橄欖華宣、宇宙光、真哪噠買書網。

## 我們的請求

貴社的出版品——特別是台語與白話字文獻、台灣教會史料,以及《台灣教會公報》——在華人教會出版中有其獨特而不可替代的位置,目前的書目裡沒有這一塊,是明顯的缺口。我們希望能將貴社出版品納入收錄,並就取得資料的方式徵詢貴社意見。以下三種方式,任何一種我們都可以配合：

**一、提供書目檔案(我們最希望的方式)**

由貴社匯出一份書目清單(Excel 或 CSV),我們直接匯入。這對雙方都最省事,資料也最準確——不會有系統誤判。若貴社能定期(例如每月或每季)提供更新檔,新書就能持續同步。

希望包含的欄位見文末附錄;若貴社現有的匯出格式與附錄不同,以貴社方便為準,我們自行對應。

**二、開放資料介面**

若貴社的網路書房系統本身有資料匯出或 API 功能,我們可以依照貴社指定的方式取用。

**三、書面同意我們定期讀取網路書房頁面**

若前兩種方式不便,我們也可以自行從貴社網路書房(buy.pctpress.org)讀取公開的商品資訊。但貴社網站的 robots.txt 目前設定為不允許自動讀取,因此在未取得貴社同意前,我們不會這樣做。

若貴社同意此方式,我們會遵守以下自我約束,也歡迎貴社指定其他條件：

- 每日僅於離峰時段(例如凌晨)讀取一次「新品」頁面,確認有新書才進一步讀取;首次全站建檔為一次性作業,會控制速率避免影響網站
- 只取公開的商品資訊(書名、作者、出版社、ISBN、定價、簡介、封面、商品網址),不取任何會員或訂單相關內容
- 明確標示來源為台灣教會公報社,並提供購書連結導回貴社商品頁
- 貴社任何時候要求我們停止或移除,我們立即照辦

## 我們可以為貴社做的

- **免費曝光與導流**:貴社每一本書都會出現在跨書房的搜尋結果中,讀者點「購買」即連回貴社網站
- **資料勘誤回饋**:整理過程若發現書目資料有誤(例如 ISBN 錯誤、作者欄位錯置),我們會整理清單提供貴社參考
- **配合貴社的標示需求**:名稱、連結文字、Logo 的使用方式都可依貴社規範調整

若貴社願意,我們也樂意先安排一次線上或電話說明,實際看看目前的站台與收錄方式,再決定合作形式。

盼望這項服務能成為華人教會共同的資源,也盼望貴社多年在文字事工上的積累,能被更多弟兄姊妹找到。

## 附錄:希望包含的書目欄位

| 欄位 | 說明 | 必要性 |
|---|---|---|
| 書名 | 完整書名(含副書名) | 必要 |
| 作者 | 多位作者請以分號分隔 | 必要 |
| 譯者 | | 有則提供 |
| 出版社 | 若含代理他社書籍,請標明實際出版社 | 必要 |
| ISBN | ISBN-13 或 ISBN-10 | 重要(用來與其他書房的同一本書比對合併) |
| 出版日期 | 年月或年月日 | 有則提供 |
| 定價 | 新台幣 | 有則提供 |
| 簡介 | 內容簡介 | 有則提供 |
| 封面圖 | 圖片網址或檔案 | 有則提供 |
| 商品網址 | 貴社網路書房的購買頁 | 必要 |
| 分類 | 貴社自訂分類即可 | 有則提供 |
| 語言 | 特別是台語、白話字、客語等 | 有則提供 |
| 頁數 / 尺寸 / 裝訂 | | 有則提供 |
| 是否絕版 | | 有則提供 |

只有「書名、出版社、商品網址」是最低要求;其餘欄位有多少給多少,我們可以逐步補齊。

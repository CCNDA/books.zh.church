# 屬靈共同書目 v1.25.0（11/25）

屬靈共同書目整理各家華文基督教書房的書目，目前收錄五萬多本，讓大家找書、比較購書管道更方便。書一多，常常是搜尋結果太多、不知道從哪裡看起。

- 搜尋畫面新增「出版年」篩選：可以填從哪一年到哪一年，例如只看 2020 年以後出版的新書，或找某個年代的經典
- 新增「來源書房」篩選：只看某一家書房收錄的書，例如校園書房、以琳書房，方便直接到熟悉的書房購買
- 兩個篩選可以跟關鍵字、分類、作者、出版社一起用；篩選後的網址可以直接分享給別人

接下來會做出版社和作者的獨立頁面，讓大家更容易認識一位作者寫過、譯過的書。

感謝大家使用屬靈共同書目，有任何建議都歡迎告訴我們。

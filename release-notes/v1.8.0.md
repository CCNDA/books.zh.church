# v1.8.0 — 真哪噠買書網的一萬件書目進來了

屬靈共同書目新增第十一家書房:**基督教真哪噠買書(MEZU)網**(www.mezu.com.tw)——
浸信會特約書店、承襲恩膏書房,也承接代編代印。這是目前收錄來源中品項最多的一站。

## 這次多了什麼

**新增 4,633 本站上原本沒有的書**。真哪噠是「特約書店 + 總代理」型態,除了自家
「哪噠恩膏」出版品,還代理浸信會出版社、宣道、香港明道、聖言資源、建道神學院、
腓利門迦密、拾珍、中信等數十家出版社,其中不少是港澳與海外華人教會的書,
台灣書店少見。

**另有約 5,167 本併入既有書目,變成多一個購書管道**。這些書別家書房已經收錄過,
系統自動認出是同一本,你在書目頁會看到「真哪噠」和校園書房、基道、以琳、天恩、
微讀、衛理、格子外面、道聲、橄欖華宣、宇宙光並列,挑順手的地方買就好。

**聖經品項特別齊**:各款聖經、和合本、浸信會版、聖經公會、漢語聖經協會、
環球聖經公會、ALABASTER 美感聖經,連客製化封面聖經都收錄了。

## 順手做的

- 每天自動更新的書房從十家增加到十一家,真哪噠「新品上架」有新書,隔天就會出現在站上。
- 書名、作者、出版社、ISBN、出版日期、頁數、尺寸、簡介與封面都一併帶進來,搜尋一樣找得到。
- 影音、禮品、文具、客製化月曆等非書商品共 226 件不列入書目。

## 目前收錄的書房

校園書房、基道 BookFinder、以琳書房、天恩出版社、微讀書城、衛理書房、格子外面、
道聲、橄欖華宣、宇宙光全人關懷機構,以及這次加入的真哪噠買書網。

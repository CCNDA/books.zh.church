# v1.16.0 — 可以看每一版的更新了

這一版多了兩個小功能，讓大家更容易知道網站有什麼改變、收錄了哪些書房。

## 新增「版本更新紀錄」

每一頁最下面都有「版本資訊」，點進去就能看到從第一版到現在的所有更新。
有寫給讀者的說明的版本，可以點開來看這一版改了什麼。

以前首頁下面的版號是手動改的，常常忘了更新；現在會自動顯示最新的版本。

## 「關於本站」的收錄書房改成即時

「關於本站」頁面上的「目前收錄的網路書房與出版社」，以前是寫死的清單，
最近新增的**天道書樓、突破機構、浸信會出版社、麥種傳道會**都沒有列上去。

現在這份清單會直接從書目資料產生，新增書房就會自動出現，
還會顯示**每一家收錄了多少本書**，以及全站目前上架的書目總數。

## 下架非書籍商品

聖經播放器、索引貼、貼紙、文具、禮品這類**不是書的商品**，已經從書目中下架，共 146 件。
搜尋和瀏覽時不會再看到它們，書目更單純。

感謝大家使用屬靈共同書目，有任何建議都歡迎告訴我們。

# v1.17.0 — 書目更乾淨，問題處理更快

這一版主要在幕後，讓書目維持「只收錄書」，有問題的資料也能更快處理。

## 每天自動擋下非書籍商品

上一版我們下架了 146 件不是書的商品（播放器、貼紙、文具、禮品等）。
但各書房每天都會上新商品，裡面難免又夾著非書籍。

現在每天更新新書時，系統會自動檢查：

- **一看就不是書的**（例如播放器、馬克杯、手環），會先暫時下架
- **可能是書、也可能不是的**（例如貼紙書、筆記本、禮盒），會留著，標記起來請同工確認

資料都不會刪除，判斷錯了隨時可以恢復。

## 同工可以更快處理有問題的書目

我們做了一個內部後台，同工可以直接看到每一本被標記的書的完整資料，
點連結到出版社的商品頁確認，再決定上架或下架。
如果發現一般商務書籍、套組合輯這類不適合收錄的，也能直接用編號下架；
下架錯了，也可以從「已下架」找回來重新上架。

## 開始了解大家怎麼使用網站

我們加上了 Google Analytics，用來了解大家常搜尋什麼、哪些頁面最常被看，
作為之後改進網站的參考。

接下來我們會讓網站更容易被搜尋引擎和 AI 搜尋找到，並且改善視障朋友使用報讀軟體的體驗。

感謝大家使用屬靈共同書目，有任何建議都歡迎告訴我們。

# 屬靈共同書目 v1.22.0（11/17）

屬靈共同書目整理各家華文基督教書房的書目，讓大家找書、比較購書管道更方便。過去收錄的都是台灣的書房，這一版開始補上海外的華文書房，第一家是北美的天道網路書房。

- 約 9,400 本站上已有的書，書目頁多了「天道北美網路書房」的購書連結（美金標價），住在北美的弟兄姊妹可以就近買書
- 新收錄約 550 本站上原本沒有的書；書房網頁上沒有作者資料的，我們寧可先留空，不把商品編號誤當成作者
- 同一本書在不同書房各上架一次的情形，同工逐筆看過，合併了 46 組
- 之後天道北美每天的新書也會自動收進來

接下來會評估下一家海外書房，讓書目涵蓋更多地區的華人教會。

感謝大家使用屬靈共同書目，有任何建議都歡迎告訴我們。

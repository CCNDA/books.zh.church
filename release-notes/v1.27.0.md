# 屬靈共同書目 v1.27.0（11/28）

屬靈共同書目整理各家華文基督教書房的書目，目前收錄五萬多本。這一版開始，每位作者、每家出版社都有自己的頁面。

- 作者頁：一位作者寫過、譯過、編過幾本書，跟哪些人合作過，最新的書一眼看到，也能一鍵看全部
- 出版社頁：這家出版社在書目裡有幾本書、出版年份從哪一年到哪一年、最常出哪些分類
- 在首頁用作者或出版社篩選時，旁邊多了「看作者頁」「看出版社頁」的連結
- 同一家出版社的不同寫法，會合併成同一頁
- 開放 API 也加上作者、出版社的資料，方便其他事工網站引用

作者和出版社的簡介還在找可靠的來源，之後再補上。

感謝大家使用屬靈共同書目，有任何建議都歡迎告訴我們。

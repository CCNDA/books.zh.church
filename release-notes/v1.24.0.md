# 屬靈共同書目 v1.24.0（11/17）

屬靈共同書目整理各家華文基督教書房的書目，讓大家找書、比較購書管道更方便。很多書同時有正體版和簡體版，兩個版本的 ISBN 不同，在站上是兩本，讀者看到其中一本，常常不知道另一個版本也有。

- 書目頁新增「另有版本」：一本書如果有對應的簡體版或正體版，會直接列出另一個版本的書名，點了就到那本的書目頁
- 對應關係由同工一組一組確認過才顯示，不會把書名相近但其實不同的書（例如同一套書的不同冊）配在一起。第一批約 460 組候選會陸續確認、陸續出現
- 開放 API 的單本書資料也多了這一項，引用書目的網站可以一起顯示

這一版之前也調整了每日新書收錄的警報：書房只是暫時沒出新書時不再誤報，真的抓不到資料時當天就會提醒，比原本快。

接下來會繼續確認簡繁對應，也歡迎大家發現配錯或漏掉的告訴我們。

感謝大家使用屬靈共同書目，有任何建議都歡迎告訴我們。

# 屬靈共同書目 v1.26.0（11/27）

屬靈共同書目整理各家華文基督教書房的書目，目前收錄五萬多本。書目裡有繁體、簡體中文，也有不少英文原文書，找書時常常混在一起。

- 搜尋畫面新增「語言」篩選：可以只看繁體中文、簡體中文、英文，或中英對照的書
- 語言篩選可以跟關鍵字、出版年、來源書房等條件一起用；篩選後的網址可以直接分享給別人
- 每天自動更新書目時，新書也會一起分好語言
- 天道北美網路書房的書，如果書房已經下架，書目頁不再顯示購買鈕；暫時缺貨的會標示「缺貨」，連結照留

接下來會做出版社和作者的獨立頁面，讓大家更容易認識一位作者寫過、譯過的書。

感謝大家使用屬靈共同書目，有任何建議都歡迎告訴我們。

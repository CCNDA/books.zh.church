# v1.7.0 — 宇宙光的書進來了,還多了「期刊雜誌」

屬靈共同書目又長大了一點。這一版新增第十家書房:**宇宙光全人關懷機構**。

## 這次多了什麼

**宇宙光的書 1,562 本上架**。宇宙光成立五十多年,從文字、輔導、視聽到學術研究都有耕耘,書單也很有自己的樣子——靈修、全人關懷、輔導諮商、科學與信仰的對話,還有華人教會少見的「基督教與中國」研究。這些書現在都能在站上一次找齊。

其中 **387 本是站上原本沒有的新書**;其餘的因為已經在別家書房收錄過,自動併到同一本書底下,**變成多一個購書管道**——你在書目頁會看到「宇宙光」和原本的校園書房、基道、以琳等並列,可以挑順手的地方買。

**新增「期刊雜誌」分類**。《宇宙光雜誌》各期都收進來了,包含每期的目錄與內容介紹。這是站上第一次收錄期刊,之後若有其他刊物也會放在這個分類。

## 順手做的

- 每天自動更新的書房從九家增加到十家,宇宙光有新書上架,隔天就會出現在站上。
- 書名、作者、出版社、ISBN、出版日期、頁數、尺寸、簡介、目錄與封面都一併帶進來,搜尋一樣找得到。

## 目前收錄的書房

校園書房、基道 BookFinder、以琳書房、天恩出版社、微讀書城、衛理書房、格子外面、道聲、橄欖華宣,以及這次加入的宇宙光全人關懷機構。
